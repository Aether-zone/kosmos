## Usage

Spacing tokens map directly to the Tailwind spacing scale.

```tsx
<div className="p-4">
  <div className="mb-6">
    Content
  </div>
</div>
```

Use the spacing scale consistently for:

- Padding
- Margins
- Gaps
- Layout spacing
- Component internals
- Section spacing
