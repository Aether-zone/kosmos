# Dark Mode

Kosmos supports light and dark themes through semantic color tokens.

The underlying primitive colors remain unchanged. Semantic tokens map those primitives differently for each theme.

## Light

<div
  style={{
    background: 'var(--kosmos-color-background)',
    color: 'var(--kosmos-color-foreground)',
    border: '1px solid var(--kosmos-color-border)',
    borderRadius: 'var(--kosmos-radius-lg)',
    padding: '24px',
  }}
>
  <h3 style={{ margin: '0 0 8px', color: 'inherit' }}>Light theme</h3>
  <p style={{ margin: 0, color: 'inherit' }}>Background, foreground, surfaces, borders, and semantic colors use the light theme values.</p>
</div>

</div>

## Usage

Components should use semantic color tokens rather than primitive colors.

```tsx
<div className="bg-background text-foreground border-border">
  Content
</div>
```

When the theme changes, the component automatically receives the appropriate colors.

Dark values are applied by putting `.dark` (or `[data-theme="dark"]`) on any
ancestor — usually `<html>`, but any container works, which is how the two
panels above sit side by side on this page. Use the **Theme** toolbar control
to switch a story between themes.
