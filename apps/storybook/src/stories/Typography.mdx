# Typography

Kosmos provides a consistent typography system for headings, body text, labels, and other UI content.

## Semantic sizes

Semantic sizes should be preferred when defining component typography.

| Token | Size |
| --- | --- |
| `body` | `1rem` |
| `bodySmall` | `0.875rem` |
| `label` | `0.875rem` |
| `headingSmall` | `1.125rem` |
| `heading` | `1.25rem` |
| `headingLarge` | `1.5rem` |
| `display` | `2.25rem` |

## Line heights

## Letter spacing

| Token | Value |
| --- | --- |
| `tight` | `-0.025em` |
| `normal` | `0em` |
| `wide` | `0.025em` |

## Usage

Typography tokens map to the semantic typography utilities provided by Kosmos.

```tsx
<h1 className="text-4xl font-bold">
  Page title
</h1>

<p className="text-base">
  Body text
</p>

<span className="text-sm font-medium">
  Label
</span>
